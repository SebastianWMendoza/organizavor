Java File Organizer

Un organizador de archivos automático construido en Java puro usando la API NIO.2.

Funcionalidades
- Lee todos los archivos de una ruta especificada.
- Extrae las extensiones mediante manipulación de Strings.
- Clasifica automáticamente los archivos en carpetas (Documentos, Imágenes, Videos, Instaladores).
- Evita el desbordamiento de memoria usando.

Tecnologías
- Java 21+
- Java NIO.2
- API Streams

Cómo usar
1. Clona el repositorio.
2. Ejecuta la clase `Organizador.java`.
3. Introduce la ruta absoluta de la carpeta a limpiar (Ej: `C:\Usuarios\Nombre\Descargas`).
